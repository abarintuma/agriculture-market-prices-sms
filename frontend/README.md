# Agri-Market SMS - Admin Frontend

Modern **React 19 + TypeScript + Vite** web dashboard for managing Ugandan crop prices, farmer directories, and SMS broadcasts via FastAPI & Twilio.

## Key Features

- **System Overview**: Live commodity price metrics, active subscriber counts, and quick SMS blast trigger.
- **Crops & Market Prices**: Commodity catalog management and market price updates in Ugandan Shillings (UGX).
- **Farmers Directory**: Registered farmers database with instant search filtering (name, phone, district).
- **SMS Broadcast Hub**: Targeted SMS dispatch by region/district, custom advisory note composer, and live mobile phone simulator.

## Tech Stack

- **Framework**: Vite + React 19 (SPA)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 + Glassmorphic Design System
- **Icons**: Lucide React
- **Routing**: React Router v7

## Development & Build

```bash
# Install dependencies
npm install

# Start development server (Port 3000)
npm run dev

# Production build
npm run build
```
